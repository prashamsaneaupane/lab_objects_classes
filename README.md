
# Class Exercise/Lab -  Student Class

Create a Student class and use it in a program.

### Student Class Must Include

- Fields
- - String name;
- - int age;
- - double gpa;
- - String major;
- - Constructor
```
Student(String name,
        int age,
        double gpa)
```

- Method
- - displayInfo()
- - isHonorStudent()

### Sample Output

```
Student Information

Name: Alice
Age: 19
GPA: 3.8
```

```
Student Information

Name: Bob
Age: 20
GPA: 3.5
```

Create at Least Two Students

The method isHonorStudent() will return true

```
if GPA ≥ 3.5
```
